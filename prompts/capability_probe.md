# Capability probe instruction (FR-04 requirements 14-17, ADR-027, WP09)

This is a one-shot capability check, not the review. You are offered the exact
tool definitions the review will offer, including the designated final-answer
tool. Do not inspect any evidence and do not call any other tool.

Call the designated final-answer tool exactly once, with the minimal arguments
provided to you. Emit only that single tool call. Text or reasoning alongside
the one call is allowed; a second tool call, a different tool, or no tool call
at all fails this check.
