# Security Policy

## Supported versions

Daimonos is under active development. Security fixes are applied to the latest
code on `master`.

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's private
vulnerability reporting for this repository.

If private reporting is unavailable in your environment, open an issue with
minimal details and request a secure contact channel for full disclosure.

## Response expectations

- Initial triage target: within 5 business days
- We will acknowledge valid reports and coordinate remediation
- Please avoid public disclosure until a fix is available
